# AI workflow

### Tool

Codex 6.1 Sol
I used Codex to define and scrutinize the spec, turn it into work tickets, implement the code, and run automated tests.

### Where I changed or rejected

- Codex initially proposed granting access by user ID, which required recipients to sign up first. I switched to email-based grants to move development faster and let owners share before recipients sign up.
- I switched the generated UI to HeroUI. I then directed Codex to revise where controls appeared, which buttons took priority, and how the main workflows felt to use.

### Checks and Verification

I checked correctness with automated and manual tests. I used the app myself to assess UX quality, and I enforced the project structure and reviewed the code to check implementation reliability.
